Bab 00 • Pondasi Berpikir

Pahami Mental Model Sebelum Menulis Satu Baris Kode

Kebanyakan siswa RPL gagal di uji kompetensi bukan karena tidak bisa mengetik PHP, melainkan karena tidak memahami alur data bolak-balik antara Pelanggan dan Kasir. Mari kita kunci gambaran besarnya di kepala:

Sisi Pelanggan (Publik / Tanpa Login)

Pelanggan duduk di meja, membuka URL /, memilih makanan via stepper (+/-), mengisi nama dan nomor meja, meninjau ringkasan di modal pop-up, lalu menekan checkout. Data masuk secara aman via transaksi database.

Sisi Kasir/Admin (Terproteksi Login)

Kasir login di /login, memantau pesanan yang baru masuk di /dashboard, mengubah status meja (*Pending* → *Diproses* → *Selesai*), dan mengelola menu makanan (CRUD + Upload Foto).

RUMUS PASTI ALUR DATA LARAVEL:

Route (web.php) → Controller → Model / DB Transaction → View (Blade HTML)

Bab 01 • Environment & Web Server

Menyalakan XAMPP dan Mengamankan Port MySQL (3306)

Sebelum menyentuh terminal, database MySQL harus aktif. Langkah ini terdengar sepele, tetapi jika MySQL bentrok port dengan layanan lain di komputer sekolah, Laravel tidak akan pernah bisa terhubung ke database.

1
Buka XAMPP Control Panel Klik tombol Start pada modul Apache dan modul MySQL. Indikator keduanya harus berubah menjadi hijau terang.
2
Bagaimana jika MySQL Gagal Start (Port 3306 Error)? Penyebab nomor satu adalah service MySQL bawaan Windows lain yang sedang berjalan. Buka CMD Run as Administrator dan jalankan net stop MySQL lalu coba klik Start kembali di XAMPP.
3
Uji Buka phpMyAdmin di Browser Kunjungi http://localhost/phpmyadmin untuk memastikan database server siap menerima koneksi.
Bab 02 • Artisan Mastery

Membuat Proyek & Membedah Makna Perintah Sakti -mcr

Di ruang ujian Serkom, waktu adalah musuh utama. Membuat Model, Migration, dan Controller satu per satu secara manual membutuhkan waktu 10 menit lebih lama dan rentan salah ketik nama. Inilah mengapa perintah -mcr wajib Anda kuasai. 

# 1. Buat folder proyek Laravel baru
composer create-project laravel/laravel pesanmakan

# 2. Masuk ke folder proyek
cd pesanmakan

# 3. Jalankan artisan dengan flag -mcr
php artisan make:model Food -mcr
php artisan make:model Order -mcr
php artisan make:model OrderDetail -m

Bedah Anatomi Perintah: Apa Itu -mcr?

-m Migration

Otomatis membuat file cetak biru tabel database di folder database/migrations/.

-c Controller

Otomatis membuat file pengendali logika di folder app/Http/Controllers/.

-r Resource Methods

Langsung mengisikan 7 method standar CRUD: index, create, store, show, edit, update, destroy.

Konfigurasi .env (Database Koneksi): Buka file .env dan pastikan baris berikut: 
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=pesanmakan
DB_USERNAME=root
DB_PASSWORD=

Tips Laravel 11: Jika database pesanmakan belum Anda buat di phpMyAdmin, saat menjalankan php artisan migrate Laravel akan bertanya: "The database does not exist. Would you like to create it?" Ketik yes lalu tekan Enter!

Bab 03 • Database Architecture

3 Tabel Relasional & Aturan Emas Foreign Key Cascade

Ada 3 tabel utama yang harus berelasi dengan sempurna: tabel master makanan (foods), tabel pesanan induk (orders), dan tabel rincian transaksi (order_details).

1. Migration Tabel Master Makanan (foods) database/migrations/xxxx_create_foods_table.php 
Schema::create('foods', function (Blueprint $table) {
    $table->id();
    $table->string('name');
    $table->enum('category', ['Makanan', 'Minuman', 'Cemilan']);
    $table->decimal('price', 10, 2);
    $table->text('description')->nullable();
    $table->string('image')->nullable();
    $table->timestamps();
});
2. Migration Tabel Pesanan Induk (orders) database/migrations/xxxx_create_orders_table.php 
Schema::create('orders', function (Blueprint $table) {
    $table->id();
    $table->string('customer_name');
    $table->string('table_number');
    $table->decimal('total_price', 12, 2)->default(0);
    // CATATAN: ENUM disinkronkan dengan Controller dan View Blade
    $table->enum('status', ['Pending', 'Diproses', 'Selesai', 'Batal'])->default('Pending');
    $table->timestamps();
});
3. Migration Tabel Detail Relasi (order_details) database/migrations/xxxx_create_order_details_table.php 
Schema::create('order_details', function (Blueprint $table) {
    $table->id();

    // Relasi ke tabel orders dengan cascade on delete
    $table->foreignId('order_id')->constrained('orders')->onDelete('cascade');

    // Relasi ke tabel foods dengan cascade on delete
    $table->foreignId('food_id')->constrained('foods')->onDelete('cascade');

    $table->integer('quantity');
    $table->decimal('subtotal', 12, 2);
    $table->timestamps();
});
PERHATIAN ASESOR: Perhatikan urutan pembuatan file migration! Tabel foods dan orders harus dibuat terlebih dahulu sebelum order_details, karena foreign key constraint membutuhkan tabel induk sudah terdaftar di database.
Bab 04 • Eloquent ORM

Relasi Eloquent & Trik Bebas Mass Assignment

Eloquent adalah jembatan antara kode PHP dan baris tabel MySQL. Di sinilah hubungan One-to-Many dideklarasikan, dan perlindungan Mass Assignment diatur.

app/Models/Order.php 
class Order extends Model
{
    use HasFactory;

    protected $guarded = ['id'];

    // 1 Order punya BANYAK detail item
    public function orderDetails()
    {
        return $this->hasMany(OrderDetail::class, 'order_id');
    }
}
app/Models/OrderDetail.php 
class OrderDetail extends Model
{
    use HasFactory;

    // WAJIB: guarded ['id'] membuka kolom 'subtotal'
    protected $guarded = ['id'];

    public function food()
    {
        return $this->belongsTo(Food::class, 'food_id');
    }

    public function order()
    {
        return $this->belongsTo(Order::class, 'order_id');
    }
}
Mengapa $guarded = ['id'] lebih unggul daripada $fillable saat Serkom? Jika Anda menggunakan $fillable dan lupa menambahkan kolom 'subtotal', Laravel akan mengabaikan nilai subtotal tanpa menampilkan pesan error (silent fail), sehingga tagihan belanja bernilai Rp 0. Dengan $guarded = ['id'], seluruh kolom aman terisi kecuali primary key ID.

Bab 06 • Auth & Storage

Instalasi Laravel Breeze & Perintah Wajib Storage Link

Laravel Breeze menyediakan sistem autentikasi lengkap (login, register, reset password) dengan tampilan Tailwind CSS yang siap pakai. 

# 1. Pasang package breeze
composer require laravel/breeze --dev

# 2. Generator scaffolding
php artisan breeze:install blade

# Pilihan prompt:
# Stack: blade
# Dark mode: no
# Testing: 0 (PHPUnit)

# 3. Jalankan perintah wajib setelah instalasi
php artisan migrate
php artisan storage:link
npm install && npm run build
MENGAPA php artisan storage:link SANGAT KRUSIAL? Foto menu yang diunggah oleh admin disimpan di folder terproteksi storage/app/public/foods. Browser klien dilarang mengakses folder storage secara langsung demi keamanan. Perintah storage:link membuat shortcut simbolik (symlink) di folder public/storage sehingga gambar dapat dibuka lewat tag HTML <img src="{{ asset('storage/' . $food->image) }}">. Tanpa perintah ini, semua gambar makanan akan 404 Not Found!
Bab 07 • Resource Controller

Logika CRUD Master Makanan & Siklus Hidup File Foto

Modul CRUD di FoodController.php menangani 7 method Resource. Kunci nilai tambah di hadapan Asesor adalah kemampuan Anda mengelola file fisik di storage agar tidak meninggalkan file sampah saat di-update atau di-delete.

Cuplikan Store & Update dengan Storage Cleanup 
public function update(Request $request, Food $food)
{
    $validated = $request->validate([
        'name'        => 'required|string|max:255',
        'category'    => 'required|in:Makanan,Minuman,Cemilan',
        'price'       => 'required|numeric|min:0',
        'description' => 'required|string',
        'image'       => 'nullable|image|mimes:jpeg,png,jpg,webp|max:2048',
    ]);

    $imagePath = $food->image;
    if ($request->hasFile('image')) {
        // Hapus foto lama agar storage tidak membengkak
        if ($food->image && Storage::disk('public')->exists($food->image)) {
            Storage::disk('public')->delete($food->image);
        }
        $imagePath = $request->file('image')->store('foods', 'public');
    }

    $food->update([
        'name'        => $validated['name'],
        'category'    => $validated['category'],
        'price'       => $validated['price'],
        'description' => $validated['description'],
        'image'       => $imagePath,
    ]);

    return redirect()->route('foods.index')->with('success', 'Menu berhasil diperbarui!');
}
Bab 08 • Database Integrity

Transaksi Pemesanan Atomik via DB::transaction

Pemesanan makanan melibatkan 2 tabel sekaligus: baris induk di orders dan puluhan baris item di order_details. Jika terjadi error di tengah-tengah loop (misalnya satu menu sudah habis atau koneksi terputus), DB Transaction akan membatalkan seluruh perubahan secara otomatis (rollBack).

app/Http/Controllers/OrderController.php (Method store) 
public function store(Request $request)
{
    $request->validate([
        'customer_name' => 'required|string|max:255',
        'table_number'  => 'required|string|max:50',
        'items'         => 'required|array',
    ]);

    $orderedItems = array_filter($request->items, fn ($qty) => (int)$qty > 0);
    if (empty($orderedItems)) {
        return back()->with('error', 'Pilih minimal satu menu makanan!');
    }

    DB::beginTransaction();
    try {
        $order = Order::create([
            'customer_name' => $request->customer_name,
            'table_number'  => $request->table_number,
            'total_price'   => 0,
            'status'        => 'Pending',
        ]);

        $totalPrice = 0;
        foreach ($orderedItems as $foodId => $quantity) {
            $food = Food::findOrFail($foodId);
            $subtotal = $food->price * (int)$quantity;
            $totalPrice += $subtotal;

            OrderDetail::create([
                'order_id' => $order->id,
                'food_id'  => $food->id,
                'quantity' => (int)$quantity,
                'subtotal' => $subtotal,
            ]);
        }

        $order->update(['total_price' => $totalPrice]);
        DB::commit();

        return redirect()->route('customer.index')->with('success', 'Pesanan Meja ' . $order->table_number . ' Berhasil Dibuat!');
    } catch (\Throwable $e) {
        DB::rollBack();
        return back()->with('error', 'Gagal memproses pesanan: ' . $e->getMessage());
    }
}
Bab 09 • Query Optimization

Dashboard Kasir & Pencegahan Masalah N+1 Query

Di dashboard kasir, kita perlu menampilkan nama menu makanan yang ada di dalam setiap order detail. Jika Anda menulis Order::latest()->get() lalu melakukan looping $order->orderDetails di Blade, Laravel akan menjalankan query database baru untuk setiap pesanan. Ini disebut bencana N+1 Query.

Salah (N+1 Query Issue): $orders = Order::all();

Jika ada 50 pesanan, Laravel mengeksekusi 51 kali query ke MySQL! Server menjadi lambat dan asesor akan mengurangi nilai optimasi database.

Benar (Eager Loading): $orders = Order::with('orderDetails.food')->latest()->get();

Hanya mengeksekusi 2-3 query saja berapapun jumlah pesanannya, karena relasi dimuat sekaligus di memori.

Bab 10 • Bug Autopsy & Resolution

Bedah 5 Bug Kritis di Modul Sekolah Yang Sering Menjebak Siswa

Banyak siswa mengira kode mereka salah saat ujian, padahal modul acuan mereka memiliki cacat logika. Berikut adalah daftar 5 bug modul asli dan kode perbaikan zero-error kami:

Bug #1 Fatal

Ketidaksinkronan ENUM Status Pesanan

Di Modul 1 ditulis ENUM Title Case ['Pending', 'Diproses', 'Selesai'], tapi di Modul 4 dropdown mengirim "completed" dan "cancelled". Hasilnya: MySQL crash dengan error Data truncated for column 'status'.

Fixed
Bug #2 Form UX

Form Reset Tanpa old('name')

Pada form tambah/edit makanan Modul 2, tidak ada helper value="{{ old('name') }}". Saat validasi gambar gagal, seluruh deskripsi yang sudah diketik user terhapus bersih.

Fixed
Bug #3 Data Risk

Mass Assignment Kolom Subtotal

Jika siswa memakai $fillable di OrderDetail dan lupa memasukkan 'subtotal', checkout pelanggan menyimpan subtotal 0 tanpa ada notifikasi error.

Fixed
Bug #4 Data Corruption

Penghapusan Riwayat Transaksi Akibat Cascade

Penghapusan menu master di admin menghapus baris transaksi historis di order_details. Dashboard kami menggunakan null-safe operator {{ $detail->food->name ?? 'Menu Terhapus' }} agar kasir tetap aman.

Fixed
Bug #5 Storage

Penumpukan File Gambar Sampah di Storage

Gambar lama tidak dibersihkan saat admin mengganti gambar atau menghapus makanan. Kami menambahkan verifikasi Storage::disk('public')->delete() di controller.

Fixed
